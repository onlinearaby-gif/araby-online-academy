# أكاديمية عربي أونلاين - Araby Online Academy 🌟
### لتعليم اللغة العربية وتحفيظ القرآن الكريم والتربية الإسلامية وفنون الخط العربي

---

## 📖 البرامج والمناهج المتاحة
1. **تحفيظ القرآن الكريم وتجويده 🕌:**
   - حلقات فردية خاصة (One-to-One) ومجموعات صغيرة.
   - ضبط مخارج الحروف وأحكام التجويد العملية.
   - خطة حفظ ومراجعة مرنة تناسب أوقات دراسة الطفل.
   - معلمات ومعلمون مجازون ذوو خبرة وصبر مع الأطفال.

2. **المنهج المصري 🇪🇬:**
   - المرحلة الابتدائية (الصفوف 1 - 6): تأسيس القراءة والإملاء، المنهج الجديد المطوّر، القواعد النحوية، والتربية الدينية الإسلامية.
   - المرحلة الإعدادية (الصفوف 1 - 3): نصوص أدبية، النحو التراكمي الشامل، فصول القصة، ومراجعات ليلة الامتحان.

3. **منهج لغتي السعودي 🇸🇦:**
   - لغتي الجميلة (المرحلة الابتدائية): الاستيعاب القرائي، الظواهر الصوتية والإملائية، وتدريبات منصة مدرستي.
   - لغتي الخالدة (المرحلة المتوسطة): التحليل الأدبي، الوظائف النحوية، والصنف اللغوي.

4. **أكاديمية الخط العربي أونلاين ✍️:**
   - دورة علاجية مكثفة لتحسين خط الطلاب بالقلم العادي الجاف في كراسات المدرسة.
   - دورات متخصصة في خط الرقعة وخط النسخ.
   - سبورة تدريب تفاعلية مدمجة لتتبع كتابة الحروف.

## 💻 لوحة تحكم الطالب الذكية (Student Dashboard)
- متابعة مقدار حفظ السور القرآنية الحالية ونسبة التقدم.
- جدول الحصص وحلقات القرآن مع زر الدخول المباشر لقاعات Zoom.
- رفع تسجيلات التلاوة الصوتية والتطبيقات مع ملاحظات المعلم.
- شهادات تفوق باسم الطالب قابلة للطباعة PDF ومشاركتها عبر الواتساب.
